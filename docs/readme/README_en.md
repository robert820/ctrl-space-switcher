## 📖 Overview

Starting from Windows 8, 10, and 11, the operating system changed the default input method editor (IME) switching shortcut to Win + Space, while demoting language toggles to a single click of Shift. For users accustomed to classic Ctrl + Space in earlier Windows versions, this causes constant inconvenience and accidental mis-presses when switching.

Attempting to change back to Ctrl + Space in modern Windows settings often brings frustrating issues:
- **Shortcut Preempted by Other Software**: Many common productivity tools, quick search utilities, or screenshot tools use this shortcut by default. Once taken, Windows' built-in shortcut stops working.
- **Multiple Input Methods Cannot Cycle Smoothly**: If you have two or more input methods installed, Windows often gets stuck toggling between English and one language without cycling through to the next.

**Ctrl+Space Switcher** is a lightweight, standalone portable utility specifically created to solve these exact problems. With no extra runtimes needed, it works right out of the box, allowing you to enjoy seamless, natural typing once again!

## ✨ Key Features

### 1. 🔄 Smooth Multi-IME Cycling
- Solves the legacy Windows issue where multiple installed input methods fail to cycle in order.
- Seamlessly cycles across all installed input methods and alphanumeric modes with zero hesitation.

### 2. 🔍 Friendly Conflict Detection
- Built-in conflict detection alerts you when another background program is locking the shortcut.
- Provides friendly suggestions without force-closing any of your existing programs.

### 3. 💻 System Tray & Silent Auto-Start Integration
- Supports automatic silent startup with Windows, launching directly minimized to your system tray.
- Single-instance protection prevents duplicate windows; tray icon allows quick access to settings or pausing listeners anytime.

### 4. 🛡️ Comprehensive Windows Support
- Broadly supports Windows 7, Windows 8/8.1, Windows 10, and Windows 11 (compatible with both 32-bit and 64-bit systems).

## 📦 Download & Usage

### 📥 Download
1. Head over to the [Releases Page](https://github.com/robert820/ctrl-space-switcher/releases) and download the latest standalone executable.
2. The software is distributed as a **single standalone portable executable**—no installer or dependencies needed.

### 🚀 Usage Instructions
1. Double-click the executable. When the window status indicates listening, the shortcut is active.
2. Press Ctrl + Space to enjoy instant input method switching!
3. Closing or minimizing the window automatically sends it to the system tray.
