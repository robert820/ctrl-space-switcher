## 📖 軟體簡介

自 Windows 8、Windows 10 到 Windows 11，系統將預設的輸入法切換快捷鍵改成 Win + Space，並將中英文切換簡化為按一下 Shift。這對習慣早期 Windows 經典 Ctrl + Space 的使用者造成困擾，切換時經常按錯鍵。

更困擾的是，在現代 Windows 系統中嘗試改回 Ctrl + Space，常常遇到很多問題：
- **快捷鍵被其他程式佔用**：許多常見的辦公工具、快速搜尋或截圖工具預設都使用了這組按鍵。一旦被佔用，系統原本的切換功能就直接失效。
- **多種中文輸入法無法順暢切換**：如果您同時安裝了兩種以上的中文輸入法（例如注音與倉頡），系統常常卡在中英文切換，無法順暢循環切到下一種輸入法。

**「Ctrl+Space 輸入法切換器 (Ctrl+Space Switcher)」** 是一款專為徹底解決上述困擾打造的原生綠色免安裝實用工具。無須安裝額外軟體環境或支援庫，點開即可使用，讓您重溫最順手流暢的打字體驗！

## ✨ 核心功能

### 1. 🔄 智慧相容多款輸入法循環
- 解決了 Windows 系統在同時安裝多種輸入法時無法依序循環切換的困擾。
- 注音、倉頡、大易、拼音及英數狀態皆能順暢無縫循環切換，打字行雲流水。

### 2. 🔍 清晰的熱鍵衝突偵測
- 內建智慧衝突辨識機制，若有其他背景工具正在佔用快捷鍵，程式會貼心提示衝突狀態並提供改善建議。
- 絕不胡亂關閉使用者原有的程式，安全無干擾。

### 3. 💻 系統匣常駐與開機自啟動整合
- 支援開機自動靜默啟動（直接最小化常駐於右下角系統匣），開機即用無需手動開啟。
- 單一執行個體保護，防止重複開啟；托盤選單一鍵快速呼叫介面或暫停監聽。

### 4. 🛡️ 全平台相容支援
- 全面支援 Windows 7、Windows 8/8.1、Windows 10 與 Windows 11（相容 32 位元與 64 位元架構）。
